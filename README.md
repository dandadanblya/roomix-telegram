# ROOMIX — Telegram Mini App

ROOMIX — веб-приложение для планирования интерьера по фотографии комнаты. Сейчас это **рабочий фронтенд-прототип**, который открывается в браузере и внутри Telegram как Mini App. AI-сервиса пока нет.

## Что работает сейчас

- Загрузка фотографии комнаты с предпросмотром.
- Каталог из 26 позиций в 6 категориях: мебель, стены, пол, свет, декор, другое.
- Добавление и удаление позиций в «комплект».
- Добавление своей позиции (название и цена) в текущий комплект.
- Предварительная смета: сумма цен позиций комплекта.
- Сохранение списка позиций в `localStorage` на устройстве (фото не сохраняется).
- Интеграция с Telegram: `ready()` и `expand()`, нативные уведомления, тактильная отдача, безопасные отступы. В обычном браузере приложение работает как раньше.

## Чего пока нет

- AI-визуализация интерьера.
- Применение стен, пола и света к фотографии.
- 3D-просмотр (кнопка только показывает сообщение).
- Ползунок «До/После».
- Экспорт сметы и проекта в PDF.
- Смета с количеством, работами и артикулами.
- Загрузка сохранённого проекта, несколько проектов.
- Бэкенд, проверка `initData`, тёмная тема.

## Запуск локально

Откройте `index.html` в браузере. Telegram для этого не нужен: вне Telegram вместо нативных уведомлений используется обычный `alert`, а тактильная отдача отключена.

## Публикация на HTTPS (GitHub Pages)

Telegram открывает Mini App только по HTTPS-адресу.

1. Откройте репозиторий на GitHub: **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две адрес появится на этой же странице: `https://<логин>.github.io/roomix-telegram/`.
5. Откройте адрес в браузере и убедитесь, что приложение загружается.

Подойдут и другие статические хостинги (Netlify, Cloudflare Pages): сборка не нужна, достаточно выложить `index.html`.

## Подключение к Telegram

1. Откройте [@BotFather](https://t.me/BotFather) и создайте бота командой `/newbot`.
2. Выберите **Mini App** одним из способов:
   - `/newapp`: создаст отдельное Mini App, укажите HTTPS-адрес из предыдущего раздела;
   - `/mybots` → ваш бот → **Bot Settings → Menu Button → Configure menu button**: укажите тот же адрес, и приложение откроется кнопкой меню бота.
3. Откройте бота в Telegram и запустите приложение. Проверьте на телефоне загрузку фото, добавление и удаление позиций, сохранение и размер кнопок.

## Откат к прежней версии

Версия до интеграции с Telegram сохранена в релизе и теге `v0-prototype` (раздел **Releases** на GitHub). Из релиза можно скачать архив с прежним `index.html`.
